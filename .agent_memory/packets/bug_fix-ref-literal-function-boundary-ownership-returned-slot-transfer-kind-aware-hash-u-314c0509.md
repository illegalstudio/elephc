# Ref-literal function-boundary ownership: returned-slot transfer + kind-aware hash-under-Array runtime

> Function boundary ownership for the by ref array literal desugar round 4, FIX 6+7 . 1 return <assignment yield : stor…

Function-boundary ownership for the by-ref array-literal desugar (round 4, FIX 6+7). (1) `return <assignment-yield>`: store_local's plain-PhpLocal path returns its own Acquire as the yield, so a direct return double-claims one +1 (the hidden yield-temp slot AND the return value) — the epilogue release of the slot frees the caller's hash (silent UAF, allocs==frees). Fix = `reload_returned_assignment_local` in lower_return: re-load the just-stored local so the return is a LoadLocal and the EXISTING returned-slot exclusion (`direct_return_local_slots` in codegen_ir/frame.rs, which also follows ArrayToMixed/HashToMixed wrappers) transfers ownership. Gated on plain-slot PhpLocal + refcounted + defining op == Acquire. (2) A hash crossing a declared `: array` (Array(Mixed)) contract stays HASH storage: `coerce_container_to_return_type` re-stamps via HashToMixed; `__rt_array_to_mixed` early-returns kind-3 payloads; `__rt_array_free_deep` delegates kind-3 to `__rt_hash_free_deep` (x86 used to silently SKIP them = leak, ARM corrupted); `__rt_hash_to_mixed` must NOT re-box tag-11 reference buckets; `__rt_mixed_array_get`'s assoc path calls `__rt_deref_if_reference` after `__rt_hash_get`. (3) Scalar return coercions leak owned Mixed sources: coerce_to_return_type's I64/F64 arms now call `release_coercion_source_if_owned` (the Str arm already did) — this was exactly 1 Mixed element box leaked per `function(array $x): int { return $x['s']; }` call.
Evidence: q09e '41 1' heap-clean (was ' 1' UAF); q09/q09a/q09b '5 1' heap-clean; q11a/q11b/q11c live_blocks 0 (was 1/call); q11d stays 0; references 130/0, runtime_gc 126/0, parser 424/0, smoke 255/0; 4 modified x86 helpers clang-cross-assembled.
