# The "gradual array-builtin boundary" pattern (array_arg_is_gradually_acceptable in src/typ

> The "gradual array builtin boundary" pattern array arg is gradually acceptable in src/types/checker/builtins/arrays.r…

The "gradual array-builtin boundary" pattern (array_arg_is_gradually_acceptable in src/types/checker/builtins/arrays.rs, used by array_keys/array_values/sort/rsort/asort/etc. to accept Mixed/Union first args) is checker-only scaffolding with NO working EIR backend lowering for the actual Mixed/Union case. Proven by direct testing on branch reconcile/dirname-symfony HEAD 3a2bb667a: `function pick(): array|false { return [...]; } $x = pick(); array_keys($x);` and `... sort($x);` both compile past the checker (which accepts the Union arg) but FAIL at codegen with "EIR backend error: unsupported EIR backend feature: array_keys for PHP type Mixed" / "...sort for PHP type Mixed" — because PhpType::Union collapses to PhpType::Mixed via codegen_repr(), and the builtin's EIR lowering (e.g. array_combine_key_element_type, lower_sort's element-type resolution) only pattern-matches PhpType::Array(_)/AssocArray, never Mixed. This is a LOUD compile-time failure (not silently wrong), but it means the checker's gradual acceptance for this whole builtin family delivers no actual capability today — any spec item that says "mirror the array_keys/sort gradual-typing precedent" is building on a broken foundation. A future campaign wanting real gradual-array-builtin support needs to add the missing unbox-and-assert-array EIR lowering step (mirroring the ArrayAccess index-read Op::MixedBox pattern) for each of these builtins, not just extend the checker's acceptance set.
Evidence: Two isolated repros both hit `EIR backend error: unsupported EIR backend feature: {array_keys,sort} for PHP type Mixed` at the cargo run -- compile step, confirmed via php -n that the equivalent PHP is valid and array-mutating.
Verified by: cargo run -- probe scripts on reconcile/dirname-symfony HEAD 3a2bb667a

## Verification

Two isolated repros both hit `EIR backend error: unsupported EIR backend feature: {array_keys,sort} for PHP type Mixed` at the cargo run -- compile step, confirmed via php -n that the equivalent PHP is valid and array-mutating.
