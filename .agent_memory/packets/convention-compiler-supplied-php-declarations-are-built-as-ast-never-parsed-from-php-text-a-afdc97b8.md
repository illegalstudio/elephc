# Compiler-supplied PHP declarations are BUILT as AST, never parsed from PHP text at compile time

> Maintainer rule, stated 2026 09 02: when you implement a PHP function, class, constant or prelude that the COMPILER s…

Maintainer rule, stated 2026-09-02: when you implement a PHP function, class, constant or prelude that the COMPILER supplies, you construct it directly with the AST builders in crate::parser::ast (Stmt, Expr, StmtKind, ExprKind, TypeExpr and friends) — you never write a PHP source string and parse it during compilation. The canonical examples in the tree are src/web_prelude/build.rs and src/opcache_prelude/build.rs, both of which import crate::parser::ast and emit declarations rather than text, and src/tz_prelude.rs (the date/timezone migration the maintainer cites), which declares the DateTimeZone marshalling helpers and the elephc_tz externs through crate::synthetic_class with ZERO occurrences of a PHP open tag in the file. Why it matters: a text prelude is re-parsed on every compilation, escapes the checker until the last moment, and makes placeholder splicing brittle — the web prelude used to splice PHP that the opcache prelude GENERATED, so neither could stop producing text while the other consumed it. The AST form is typed, verifiable node by node, and prunable. Text-based preludes still exist as inherited upstream code and are being migrated: src/backend_gap_prelude.rs, src/version_prelude.rs, src/superglobals.rs, src/synthetic_class.rs, src/pdo_prelude.rs, src/array_reduce_prelude.rs, src/array_merge_prelude.rs and src/dom_prelude.rs still contain PHP text. Do not extend them, and do not add a new PHP source string to any .rs file. Any brief handed to an implementation agent working on a builtin, a runtime class such as __PHP_Incomplete_Class, a constant family such as ENT_*, or a builtin wrapper must quote this rule with the web_prelude/tz_prelude example.
Evidence: Maintainer instruction quoted in the session note dated 2026-09-02 ("lorsque l'on doit implémenter une fonction PHP ou une classe, on a l'AST, on ne doit pas parser du PHP, on a déjà migré la partie date si tu veux un exemple").
