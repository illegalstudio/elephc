# Interpreter-declared classes under an eval context: constant cells were per eval context (autoloaded interface constant as a parameter default failed), nullable/boxed reflection receivers read static AOT metadata (getMethods() = 0), and reflector targets were registered per eval context

> Commit f7a17151de 7 files, +446/ 18 . Attribution first: the empty getMethods under an eval context was NOT a regress…

Commit f7a17151de (7 files, +446/-18). Attribution first: the empty getMethods() under an eval context was NOT a regression of b7ad5cb0d7 — with its nine files materialized at 369c234027 and the compiler rebuilt, the 30-line reducer failed identically (getConstant=false, `Fatal error: eval() runtime failed`), and the brief's simple reducer (AOT class with camelCaseOne/plain, eval context, interpreted variant) actually passed at HEAD; the AOT method-table row-name lead was a dead end because the failing classes are interpreter-declared and that table is never consulted. Three real mechanisms: (1) constant cells were per-eval-context — a class-like declared inside a nested eval invocation (an autoloader's include) reaches other contexts through sync_global_eval_classes, which copied the declaration but not the constant value cells (trace: init_const in one ctx, const_fetch in another finds the declaration, not the cell), so eval_class_constant_fetch_result returned RuntimeFatal and the reflection reader a silent false; fix: eval_class_like_constant_cell in crates/elephc-magician/src/interpreter/statements/enum_declarations.rs materializes a constant on first read under the declaring class's magic scope and caches it, used by static_property_access.rs and by the reflection constant readers (class_member_api.rs, formatting.rs). (2) Reflection routing read one statically known class: a nullable `?ReflectionClass` return and a boxed/Mixed receiver were answered first by the nullable and mixed paths running the synthesized reflection body, which reads generated AOT metadata — empty for an interpreter-declared class — hence getMethods() = 0 and getMethod() throwing while getName()/hasMethod() were right (they read the reflector's own slots); fix: boxed_reflection_receiver_needs_eval_bridge in src/codegen/lower_inst/method_dispatch.rs routes a union receiver whose arms are all built-in reflectors to the bridge, and the mixed-dispatch candidate arm routes a MATCHED reflection class to the bridge (runtime-checked). (3) A reflector's target is registered per eval context under the object's runtime identity, so one built in another frame carried no binding and every eval-backed handler declined; fix: eval_rebind_foreign_reflection_target in crates/elephc-magician/src/interpreter/statements/method_dispatch.rs recovers the target from the reflector's __name/__declaring_class slots, GATED to class-likes the interpreter itself declared. A dropped attempt: declaring an eval context for reflection receivers in ir_lower fixed a non-web reducer but broke test_reflection_get_file_name_reports_the_declaring_file — not shipped; the rebinding gate exists for the same reason. Tests: 3 in tests/codegen/oop/reflection_regressions.rs (autoloaded interface constant as parameter default, boxed reflector listing an autoloaded class's methods, reflector built in another eval frame), all pinned against php -n. Filters: reflection 158 reds at HEAD → 158 after with byte-identical name sets (passing 188 → 191); eval_bridge 11/0, destructors 44/0, class_exists 12/0, references 2, method_exists 5/1, runtime_gc 35, objects:: 17, autoload 120/1. Container probe AbstractRecursivePass::getReflectionMethod driven standalone now matches php -n (setConfigCacheFactory/generate/warmUp public=yes). Symfony --web rebuild (691 s): the router.default blocker is GONE; the request now dies with a runtime `Fatal error: Object could not be converted to string` (no class, no location, worker exit 1). Still open: hasConstant() returns int 1 not bool; getMethods() on FrameworkBundle Router returns 22 entries where php returns 20; a function that owns NO eval context still cannot route reflection metadata to the bridge; new ReflectionClass($var) did not trigger a registered autoloader in two shapes without an explicit class_exists first.
Evidence: Pre-commit A/B with the nine files of b7ad5cb0d7 at 369c234027 (identical failure); ELEPHC_EVAL_TRACE showing init_const vs const_fetch contexts; reducers php -n vs elephc before/after; reflection filter name sets byte-identical; standalone container probe output; Symfony rebuild + request verdict.
Verified by: commit f7a17151de; php -n; ELEPHC_EVAL_TRACE; cargo test filters; Symfony --web rebuild + curl
