# Discovered while generalizing __rt_closure_bind (L2 spec, cycle7): (1) The pre-generalizat

> Discovered while generalizing rt closure bind L2 spec, cycle7 : 1 The pre generalization x86 64 rt closure bind objec…

Discovered while generalizing __rt_closure_bind (L2 spec, cycle7): (1) The pre-generalization x86_64 __rt_closure_bind object-capture path called `mov rdi, rdx; call __rt_incref` but `__rt_incref`'s x86_64 ABI reads its argument in RAX (see emit_incref_linux_x86_64 in src/codegen/runtime/arrays/incref.rs), not RDI — a latent bug, silently harmless only because it was never exercised (old code fatal'd on any capture shape other than exactly one $this). Fixed in the rewrite (now uses rax). (2) Calling a closure MULTIPLE TIMES when it returns a captured local (`function() use ($label) { return $label; }` called twice) returns the correct value on the FIRST call and an EMPTY STRING on subsequent calls — reproduced with zero Closure::bind involvement, so it's a pre-existing gap in repeated closure invocation / captured-value return, not something introduced by closure_bind. Out of scope for the closure_bind generalization (perimeter did not include call-argument/invoker materialization); documented as residual. (3) `Closure::bind()`'s literal-null $newThis argument lowers through Op::ConstNull at PhpType::Void, which ALWAYS materializes as NULL_SENTINEL (0x7fff_ffff_ffff_fffe), never plain 0 — any runtime helper receiving a "$newThis or none" argument must compare against NULL_SENTINEL (via abi::emit_load_int_immediate + cmp), not just cbz/test reg,reg, or it will misdetect "no new $this" as present. (4) A local variable holding a Closure::bind() result (PhpType::Callable, Ownership::MaybeOwned) appears to leak at top-level scope exit even when never invoked (--heap-debug showed live_blocks=3 for two closures + one bind with no calls) — likely a pre-existing gap in Callable-typed BuiltinCall-result scope-exit release, since the old $this-only closure_bind was "not directly testable" per its own doc comment (every reachable shape hit the old capture-count fatal before a leak could ever be observed). Not fixed (out of scope/high risk under time pressure); documented as residual for a future task.
