# `return $this` under a boxing return type (nullable object, mixed, object union) must not retain the owning temporary the coercion just minted

> Commit 4d96033129. return $this returns a BORROWED receiver, so acquire returned this src/ir lower/stmt/control exit.…

Commit 4d96033129. `return $this` returns a BORROWED receiver, so `acquire_returned_this()` (`src/ir_lower/stmt/control_exit.rs`) retains it to balance the caller's release. That is right only while the returned value still IS the receiver pointer. A declared return type that cannot carry a bare object pointer — `?C`, `mixed`, `C|Other` — makes `coerce_to_return_type()` box it first into a fresh OWNED Mixed cell, and the acquire then added a +1 nobody ever dropped (EIR: `v3 = mixed_box v2` already owned, then `v4 = acquire v3`). Consequence: a discarded fluent temporary `(new C('x'))->nul([]);` was never destructed for those three return types while `: C` was fine (php prints 6 destructor lines on the 6-case probe, elephc printed 3); the eval release trace showed the discarded temp released at `cell_refs=2` instead of 1. Fix: `acquire_returned_this()` receives the pre-coercion value and skips the retain when the coercion replaced the borrowed receiver with an owning temporary — the same `ctx.value_is_owning_temporary()` guard its sibling `acquire_borrowed_return_value()` already applies; an unchanged value still takes its retain, so a live receiver is never destructed early (asserted by a test). Four value tests in tests/codegen/destructors.rs (destructor output and ORDER for the three boxed return types, a live receiver surviving a boxed `return $this`, chain ordering, --heap-debug clean). Filters unchanged (destructors 19→23 tests 0 failures, runtime_gc 35, references 2, nullable 5, locals_retype 8, objects:: 17, eval_bridge 11). NOT the Symfony `secrets.local_vault` blocker: the Symfony configurator methods return `Heap(Object)` and never take the boxed path (checked in the IR; post-rebuild refcounts identical).
Evidence: 6-case standalone probe: php -n 6 destructor lines, elephc 3 before and 6 after, byte-identical, --heap-debug clean; EIR dump showing mixed_box followed by acquire; eval release trace cell_refs=2 vs 1.
Verified by: commit 4d96033129; php -n; --emit-ir; --heap-debug
