# Discovered a severe PRE-EXISTING infinite-loop bug (reproduces on unmodified HEAD 54ed696d

> Discovered a severe PRE EXISTING infinite loop bug reproduces on unmodified HEAD 54ed696d9, unrelated to any M2 cycle…

Discovered a severe PRE-EXISTING infinite-loop bug (reproduces on unmodified HEAD 54ed696d9, unrelated to any M2 cycle-8 changes): compiling ANY of these hangs the elephc compiler itself (even at `--check`, before codegen): (1) `count($x)` where `$x` is a function parameter declared `array|false` (or any union containing an array member) — hangs with ZERO array-mutating builtins involved, just reading a union-typed value once; (2) a variable started as `[]` then conditionally reassigned inside a nested `if` to a Mixed-boxed array (e.g. `$hosts = []; if (...) { if (!is_array($hosts = $query['host'])) throw ...; }`) hangs when READ a second time afterward via `count($hosts)`/`$hosts[0]`/`implode(...)`, OR when a gradual-typing-accepting by-ref builtin (`sort()`, `array_unshift()`) is called TWICE on the same such variable, OR when the variable is aliased first (`$b = $a;`) then used again. The ONE safe pattern that does NOT hang: a single call to a gradual-accepting builtin on such a variable whose ONLY subsequent use is the builtin's own return value (e.g. `$n = array_unshift($hosts, 9); echo $n;` compiles and runs correctly, printing the right mutated count). This blocks writing richer end-to-end tests (COW-aliasing observation via content reads, multi-call chains) for any newly-accepted union/Mixed array_unshift-family work until this checker/ir_lower-level bug (likely in flow-sensitive type narrowing or a liveness/CFG analysis that doesn't converge for reassignment-merged or declared-union locals) is fixed. Also separately reproduced: an UNCAUGHT (no try/catch) TypeError thrown from a dynamic-argument reflection ctor (e.g. `new ReflectionClass($x)` with a bad `$x`) hangs at RUNTIME (pre-existing `__rt_throw_current`/top-level-fatal-handler gap) even though the identical throw sequence works fine when caught by a try/catch.
Evidence: Reproduced via `cargo run -- --check` with `timeout`/background-process kill checks on both the M2-cycle8 working tree AND a clean `git stash` of it (base commit 54ed696d9): `function f(array|false $x) { echo count($x); }` hangs `--check` alone. Also reproduced: `sort($hosts); sort($hosts);` on a reassignment-merged Mixed local hangs `--check`.

## Verification

Reproduced via `cargo run -- --check` with `timeout`/background-process kill checks on both the M2-cycle8 working tree AND a clean `git stash` of it (base commit 54ed696d9): `function f(array|false $x) { echo count($x); }` hangs `--check` alone. Also reproduced: `sort($hosts); sort($hosts);` on a reassignment-merged Mixed local hangs `--check`.
