# Param-source ref-entry seeding: zero-init must skip param slots; Mixed params need an acquire; by-ref params go loud

> FIX 8 round 4, array literal by ref entries : a hoisted entry block Op::LocalRefEnsure for a PARAMETER read 0 because…

FIX 8 (round 4, array-literal by-ref entries): a hoisted entry-block Op::LocalRefEnsure for a PARAMETER read 0 because zero_initialize_local_ref_ensure_main_slots in src/codegen_ir/frame.rs runs AFTER the prologue Pass-1 parameter spill and zeroed the param slot, destroying the incoming argument before the ensure could adopt it. Fix: skip slots with LocalSlotId raw < params.len() in that pass (param slots are always live post-spill, never garbage). Two companion guards: (1) a Mixed-repr parameter arrives as a CALLER-owned boxed cell that the caller releases post-call, while __rt_ref_cell_ensure adopts by MOVE — the ir_lower hoist in lower_body_into_function must emit acquire_if_refcounted on the incoming box before the ensure or heap-debug reports a bad-refcount fatal and string payloads read empty (int payloads silently read stale 42 — UAF). Array/int params need NO acquire (array argument handles transfer to the callee; adding one would leak). (2) by-ref params and by-ref use-captures hold the caller's raw reference ADDRESS, not a kind-6 cell — wrapping it yields silent pointer garbage; the checker now rejects them loudly via the new Checker::declared_byref_param_locals set (seeded only by with_local_storage_context, never by =&-bind sites, so re-binding an already-bound local keeps sharing its one cell).
Evidence: w03_param_source probe: '0 1' before, '13 1' after (PHP '13 1'); w05 mixed param: bad-refcount fatal before, '42 1|zz' heap-clean after; w06 by-ref param: silent raw address 6136963992 before, loud checker error after; references suite 144/0, runtime_gc 126/0, ir_backend_smoke 255/0
Verified by: cargo test --test codegen_tests references (144/0) + --heap-debug probes on the w03/w05/w16 family
