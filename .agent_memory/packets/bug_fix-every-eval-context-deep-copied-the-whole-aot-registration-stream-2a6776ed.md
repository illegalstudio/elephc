# Every eval context deep-copied the whole AOT registration stream

> sync global eval aot metadata handed each new ElephcEvalContext a metadata.clone of the whole GlobalEvalAotMetadata :…

`sync_global_eval_aot_metadata` handed each new `ElephcEvalContext` a `metadata.clone()` of the whole `GlobalEvalAotMetadata`: sixteen tables (native_methods, native_static_methods, native_constructors, native_class_parents, five attribute maps, two property-hook maps, native_property_types, native_property_defaults, native_functions, and the three declared_*_names vectors). On a Symfony `--web` request the eval bridge creates a context per probed call, so that copy plus the matching free dominated the request.

The tables are immutable after publication, so the fix is to reference-count them instead of copying. Every one of those fields is now `Arc<...>` on both the context and the published snapshot; the static holder became `Mutex<Option<Arc<GlobalEvalAotMetadata>>>`; `publish_global_eval_aot_metadata` stores `Arc::clone` of the first context's own tables; `sync` adopts the same allocations. The lock is now held only long enough to clone one pointer, and `context_free` drops refcounts instead of freeing sixteen maps. The publication contract is unchanged: it is still an unconditional `*metadata = Some(...)` replace, so a `OnceLock` would have silently changed semantics and was deliberately NOT used.

THE HAZARD, and why it is now a compiler guarantee rather than a promise: a write must never reach a shared table. All 48 registration setters (functions.rs 8, native_metadata.rs 9, native_signatures.rs 23, classlike_objects.rs 6, classes_aliases.rs 6) go through `Arc::make_mut`, so a context that registers after adopting the snapshot silently forks its own copy -- an `Arc<HashMap>` exposes no other mutable path. Semantics are identical to before (sync used to deep-copy and the copy was mutated); the fork now happens on the first write and only for the table actually written. Guarded by the unit test `a_registration_after_adopting_the_shared_table_forks_it`.

Two things that fell out:
- `NativeFunction::descriptor` moved from `*mut c_void` to `usize`, cast at its single use in `NativeFunction::call`. That is what makes `NativeFunction` Send+Sync, and it let `GlobalNativeFunction`, `snapshot_native_function` and `restore_native_function` be deleted outright -- they existed only to launder that raw pointer across the mutex.
- `interpreter/statements/native_constructor_defaults.rs:89` re-syncs MID-request whenever a constructor signature is missing. That was a full deep copy in the middle of interpretation, once per miss; it is now a pointer swap. This is likely the larger half of the win.

MEASURED on one Symfony `--web` request (examples/symfony-app/public/index.php, worktree root, single worker), before vs after, same binary path, same stop:
- wall, untraced, 3 runs: 4901/6268/5070 ms -> 698/728/836 ms (median 5070 -> 728, a 7x cut).
- traced: 6.0 s -> 1.13 s.
- worker `sample`, untraced: 2636 -> 177 top-of-stack samples; allocator + bulk copy 69.3% -> 19.2%.
- the eval trace is byte-identical after normalising addresses: 5444 lines both sides, same stop (`class_exists("Symfony\Component\ExpressionLanguage\ExpressionLanguage")` -> `ClassExistenceResource::throwOnRequiredClass` -> RuntimeFatal -> index.php:576).
The compiler binary is NOT rebuilt by this change (only the magician staticlib is), so generated code is identical by construction rather than by spot check.
Evidence: Symfony --web request before/after: wall median 5070 ms -> 728 ms untraced; traced 6.0 s -> 1.13 s; worker sample 2636 -> 177 top-of-stack samples with allocator+bulk-copy 69.3% -> 19.2%; ELEPHC_EVAL_TRACE identical at 5444 lines with the same stop after normalising heap identities and ports. cargo test -p elephc-magician --lib: 1287 passed (base 1286; the +1 is the new fork test), same 16 pre-existing failures by name. codegen_tests include_builtin_classes + include_deferred_classes: 7 passed, 0 failed.
Verified by: cargo test -p elephc-magician --lib; cargo test --test codegen_tests -- include_builtin_classes include_deferred_classes; scratchpad exec-lane webserve.sh + tracediff.sh + sampshare.sh against examples/symfony-app
