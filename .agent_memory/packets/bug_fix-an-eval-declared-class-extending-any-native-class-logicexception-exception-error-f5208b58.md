# An eval-declared class extending ANY native class (LogicException, Exception, Error, Array

> An eval declared class extending ANY native class LogicException, Exception, Error, ArrayObject, SplStack, ... failed…

An eval-declared class extending ANY native class (LogicException, Exception, Error, ArrayObject, SplStack, ...) failed to declare with 'class X could not be declared', stage=validate_aot_parent_requirements. Mechanism: codegen's runtime_class_infos() trims a native class's method_impl_classes/static_method_impl_classes down to methods whose EIR body (or intrinsic wrapper) actually got emitted this build -- correct for vtable emission, which must not reference a dead-code-eliminated symbol. But the eval reflection bridge's ABSTRACT bit read '!method_impl_classes.contains_key(method)' as its abstract signal, so any concrete native method unreachable from AOT-compiled code (e.g. Exception::getMessage()/getCode() when only interpreted/eval code calls them, which is exactly the shape of a --web app whose only compiled entry point is a bootstrap file) got reported ABSTRACT. The eval class-declaration validator then treated it as an unmet abstract-parent requirement for every native ancestor, even though real PHP has zero abstract methods in the whole Exception/Error/ArrayObject/SplStack hierarchy. Fix: added ClassInfo.abstract_methods/abstract_static_methods, populated identically to method_impl_classes at checker build time but NEVER trimmed by codegen reachability, and switched the reflection ABSTRACT-bit reads to consult these new untrimmed fields instead of method_impl_classes presence.
Evidence: gate.php probe table went from stage=validate_aot_parent_requirements RuntimeFatal on all 11 native bases to 17/17 IDENTICAL against php -n; ELEPHC_EVAL_TRACE showed the exact failing stage before and after
Verified by: tests/codegen/eval_native_method_retention.rs::test_eval_class_can_extend_a_native_exception_and_be_caught_by_its_parent_type (compile_and_run end-to-end test); revert sentinel reproduced the original class-could-not-be-declared text; php -n 8.5.6 as oracle for a 17-probe gate
