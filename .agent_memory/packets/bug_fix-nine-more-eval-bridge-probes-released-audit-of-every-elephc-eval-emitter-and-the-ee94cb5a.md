# Nine more eval-bridge probes released (audit of every __elephc_eval_* emitter) and the spread container box released; the remaining leak is the interpreter treating owned array_get cells as borrowed

> Commits 1216db5895 and 43ee935242. 1 AUDIT: every emitter that hands a cell to elephc eval was checked against the un…

Commits 1216db5895 and 43ee935242. (1) AUDIT: every emitter that hands a cell to `__elephc_eval_*` was checked against the uniform contract stated on the runtime side — each bridge entry takes `RuntimeCellHandle::from_raw` (`Copy`, no `Drop`) and anything the interpreter keeps it retains itself (`register_spl_autoload_callback_unchecked` calls `values.retain` before storing) — so a box made with `emit_box_current_value_as_mixed` stays the frame's to release on every exit. Nine more emitters lacked it: `lower_eval_is_callable`, `lower_eval_member_exists`, `lower_eval_class_relation`, `lower_eval_object_class_name`, `emit_eval_object_is_a_named_fallback`, `lower_eval_object_is_a_dynamic`, `lower_eval_callable_call_array`, `lower_eval_spl_autoload_register` (`src/codegen/lower_inst/builtins/eval/introspection.rs`), `lower_eval_function_call_array` and `lower_eval_owned_function_call_array` (`dynamic_calls.rs`), `lower_eval_native_object_new` and `_fallback` (`native_object_construction.rs`). Four ABIs answer a plain int in the register the release helper reuses: `emit_release_eval_boxed_operands_keeping_int_answer` parks it in the unused scratch result slot. Left alone on purpose: two static-property writes (`context.set_static_property` stores the caller's cell WITHOUT retaining — a release there is a double free) and two process-exiting paths. Reducer: `function run(){ eval('$seed = 1;'); $local = new T('local'); var_dump(is_callable($local)); echo "scope end\n"; }` — php prints `destruct local` after `scope end`, elephc printed nothing. Attribution name for name: 115 distinct failures over static/late/callable/eval_callables/eval_closures/eval_builtin_parity/runtime_gc/references/nullable/locals_retype/objects:: (29/5/24/4/4/3/35/2/5/8/17) all fail at HEAD too. (2) SPREAD CONTAINER: `coerce_eval_function_arg_array` (`src/ir_lower/expr/callable_probes.rs`) boxed the spread container with a raw `Op::MixedBox` that nothing released (twice when the container was itself an owning temporary, since the raw box bypassed `box_value_as_mixed`); now boxed through `box_value_as_mixed` and paired with `release_owned_call_arg_temporaries` at both call sites (`lower_dynamic_function_owner_spread_call`, `lower_eval_call_user_func_array_fallback`); --heap-debug on a two-spread probe 12 blocks/880 B → 8/496; fixture `test_spread_call_under_an_eval_context_releases_its_boxed_container` pins stdout and the block count. STILL OPEN, mechanism proven: an OBJECT element of a spread never destructs under an eval context because `__rt_mixed_array_get` (`src/codegen_support/runtime/objects/mixed_array_get.rs`) returns OWNED cells (increfs a stored boxed cell or freshly boxes a typed slot), while every consumer of `EvaluatedCallArg.value` in the magician treats them as BORROWED (args bound `ScopeCellOwnership::Borrowed`, teardown drains only owned cells, the native path releases only its temp array); releasing at the read would hand the callee freed storage on a typed slot, so the release must happen AFTER the call (ownership flag on `EvaluatedCallArg` threaded through `bind_evaluated_native_function_args`/`reference_writeback`, ~24 sites; release points `native_execution.rs` or bind as `Owned` for `drain_owned_cells`). Also pre-existing: `echo takesInt(...$args);` under an eval context fatals with `Call to undefined function takesint()` while discarding the call is correct. Test-running gotchas: the `callable` filter takes ~18 min (not a hang; 112 eval-family tests ≈ 1017 s) — chunk with `xargs <test-binary> --exact --test-threads=2 < names.txt`; the PREBUILT test binary also needs `RUST_MIN_STACK=33554432` (exit 134 in `test_pdo_connect_failure_populated…`, which the `late` filter matches).
Evidence: Reducers php -n vs elephc before/after per probe; 115-name union re-run by exact name at HEAD (115 failed, 0 passed); --heap-debug block counts 12→8, 7→5, 9→7; emitted assembly of the spread call showing the released box, result, $local and $args; eval release trace on the real --web binary (620 configurator releases, cell_refs=1 uniform, object_refs 1..16 with 6/620 at 1).
Verified by: commits 1216db5895 and 43ee935242; php -n; --heap-debug; ELEPHC_EVAL_RELEASE_TRACE on the running server
