# Local retyping campaign (checker side): a PHP variable is a Mixed cell, so every incompatible reassignment widens instead of being refused — six root causes, from a lent reference to a by-reference parameter decided program-wide

> PHP lets a variable be reassigned to a value of any type, at any depth, and a by reference cell is untyped after bind…

PHP lets a variable be reassigned to a value of any type, at any depth, and a by-reference cell is untyped after binding. After the origin/main merge (af9d90e19d) the checker's upstream `merge_local_assignment_type` refused any unmergeable reassignment unless the slot was provably abandonable, which rejected 234 shapes in the stock Symfony fixture. The campaign that brought that to 0 (2026-09-02, eight commits) established these rules, each with end-to-end value tests against php -n in tests/codegen/locals_retype.rs and decision tests in tests/error_tests/type_system.rs: (1) 46b8935a80 + a61b5de243 — `Checker::local_binding_is_widenable` (src/types/checker/mod.rs) widens an incompatible store to the frame slot's boxed storage instead of refusing, at any conditional depth, once the lowering joins were fixed; every other guard stays (superglobals, $argv, global, static, =&, by-ref params, and the --strict-locals hard error). (2) 2c36f00a7a — `Checker::ref_aliased_locals` conflated two facts: a LASTING alias (=&, use (&$x), both names of foreach ($a as &$v)) leaves a cell alive and must not be widened (store_local refuses to widen such a slot, so widening it would miscompile), whereas a variable merely LENT to a by-reference parameter for one call (sort($c), array_shift/pop/splice, uksort, preg_match_all's out parameter) keeps its own frame storage; the kill keeps the union, the widening reads the narrower `Checker::ref_bound_locals`. (3) 0e72dbf0da — assigning a superglobal ($_GET = listOf()) stores INTO program storage whose type (AssocArray{Str,Mixed}) the assignment cannot change; both the merge and the widening treated it as a local binding; lowering converts an indexed array to that hash for any value, not only a literal (src/ir_lower/stmt/local_assignments.rs). (4) c2d9afef2a — an eval() in the body stops a local from being KILLED (ending a binding drops the slot the fragment addresses by name) but not from being widened (widening gives the local the boxed slot the eval scope wants). (5) dce8bd4ae8 — a straight-line store at depth 0 into storage this frame owns NARROWS a union binding to what it actually stored; `merged_assignment_type` used to answer the pre-store type whenever the value fit. (6) 263f02a5f2 — a store through the value variable of a by-REFERENCE foreach is an ELEMENT write, not a local retype: `loop_carried_storage_types` (src/types/checker/loop_storage.rs) takes the ($source as &$value) pair when the source is a plain local and joins what the body stores into $value onto $source's element type on every fixed-point iteration, so the ArrayToMixed conversion is emitted in the loop preheader; the stored types are re-derived rather than read off the joined entry because `apply_assignment_evidence` ends with `.unwrap_or(Mixed)` and an unanswerable value must not count as evidence. (7) 84fc5e10d5 — a by-reference PARAMETER's cell is decided program-wide: `Checker::scan_widened_ref_params` (src/types/checker/ref_param_widening.rs) runs once over every body before any is walked, asks through `merged_assignment_type` whether the declaration keeps its codegen_repr under what the body stores, and publishes the decision into the callee's seeded environment, `by_ref_local_storage_types`, and the resolved signature, so the callee's slot, the argument coercion and `ref_place_args` read one fact; three guards proved necessary: the call boundary keeps the declared type for arguments the declaration rejects (php throws `Argument #2 ($i) must be of type int, string given` and so must we), a builtin's registered return type means unknown rather than a union (taking it as evidence boxed the usort prelude and segfaulted usort over objects), and two pre-existing narrowings were removed. Residuals recorded, not fixed: 48 bytes per widened local leak at frame teardown, 192 bytes for a by-ref foreach without unset, 384 bytes per by-reference cell (all pinned at their exact numbers); PHP's Deprecated notice on non-numeric string increment is not emitted; transitive by-ref chains through a closure `function (&$x)` or an untyped &$x still error.
