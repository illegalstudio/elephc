# A `native integrity error` mid-compile means the on-disk native artifact no longer matches what this compiler expects — reinstall it, do not debug the compile

> A compile that stops with native integrity error is not a defect in the program being compiled: the cached native dep…

A compile that stops with `native integrity error` is not a defect in the program being compiled: the cached native dependency artifact on disk (pcre2 and its shim, in practice) no longer matches the identity this compiler build expects. The identity is a tuple — package, version, recipe revision, source hash, target, ABI and toolchain fingerprint — assembled in src/native_deps/doctor.rs and checked against the receipt; any one field moving invalidates the archive. It happens two ways in practice: an artifact directory left EMPTY by an interrupted install, and an artifact whose hash simply predates a change to the recipe (one measured case had the on-disk pcre2 artifact at one hash while the current elephc expected another). The recovery is a reinstall, not an investigation: `elephc native install --locked --offline --target macos-aarch64` (the `native` subcommand is selected by an exact `args[1] == "native"` in src/cli.rs). Two related cautions. Any edit to a shim source under src/native_deps/recipes/ must bump recipe_revision in src/native_deps/catalog.rs, or the stale archive is reused and the edit appears to do nothing. And a reinstall RACES with a running compile that reads the same artifact — one session saw a measurement and a `native install` overlap — so do not reinstall while another agent's build is live; check for one first.
Evidence: Two occurrences during the campaign of 2026-09-02..03 (session notes of those dates): an empty native artifact directory producing `native integrity error` and cleared by `elephc native install --locked --offline --target macos-aarch64`; and a size-measurement run where the on-disk pcre2 artifact hash differed from the one the current elephc expected, forcing a hand link of the probe, with a suspected race against a concurrent native install.
