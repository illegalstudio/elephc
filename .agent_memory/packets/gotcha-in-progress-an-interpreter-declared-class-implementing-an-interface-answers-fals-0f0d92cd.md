# IN PROGRESS: an interpreter-declared class implementing an interface answers false to instanceof its own class when a second eval context asks, and interfaces with methods are excluded from dynamic-instanceof metadata

> Two measured facts behind the Symfony web ServiceLocatorTagPass failure a ServiceClosureArgument reaching string $v ,…

Two measured facts behind the Symfony --web ServiceLocatorTagPass failure (a ServiceClosureArgument reaching (string) $v), found by the échelon 34 agent on 2026-09-05 before it was stopped; the fix is on disk UNCOMMITTED at HEAD 4c645c3838 (+35/-3 in crates/elephc-magician/src/context/classlike_objects.rs and crates/elephc-magician/src/interpreter/builtins/symbols/is_a.rs). Fact 1: a reducer with three AOT classes (interface, Reference with __toString, a class implementing the interface) fed from four origins (AOT array literal, runtime-included file, Mixed property read through ?? null, inside a function owning an eval context) answers identically to php -n in a PLAIN build; only the eval-bridge path diverges. Fact 2: the AOT gate class_interfaces_supported_for_dynamic_instanceof in src/codegen/runtime_metadata/classes.rs excludes from the dynamic-instanceof metadata any interface that declares a method; Symfony's ArgumentInterface declares methods. Fact 3 (reproduced): a class declared by the interpreter that implements an interface answers false to instanceof of its OWN class when asked from another eval context, because is_a resolved the owner's class NAME against the asking context's own table (dynamic_object_class) and lost the class whenever the asker had not declared a class of that name, so every relation answered false. The uncommitted fix adds dynamic_object_declaring_class, which returns the class together with the context that declared it (owner-last order so a context that knows the object keeps deciding), and is_a asks the declaring context. Open: this explains the false answer on the object's own class, not yet the true answer on Reference; the remaining candidates are the checker's narrowing after instanceof Reference standing in for the runtime test, or the AOT metadata gate. Nothing verified beyond the reducer: no tests, no filters, no commit, no rebuild.
