# parent::__construct(...) called from an eval-declared class whose resolved parent is a NAT

> parent:: construct ... called from an eval declared class whose resolved parent is a NATIVE class e.g. class Sub exte…

parent::__construct(...) called from an eval-declared class whose resolved parent is a NATIVE class (e.g. class Sub extends LogicException { function __construct(...) { parent::__construct(...); } }) failed with 'unsupported StaticMethodCall expression'. Mechanism: eval_native_static_syntax_method_result (native static-call dispatch) looks up the method via eval_aot_method_dispatch_metadata_in_hierarchy, whose index is built from collect_eval_native_instance_methods -- which deliberately skips __construct, since constructors have their own separate registration table keyed for allocation-time dispatch (new X()), not for parent:: static-call syntax. So __construct was invisible to every dispatch branch and fell through to the 'undefined method' fallback. PHP runs the parent constructor against the SAME object ($this), not a freshly allocated one -- exactly what eval_native_constructor_with_evaluated_args (via construct_object_for_class, the same AOT constructor bridge new X() already uses when X has no own constructor) does. Fix: added an explicit __construct branch at the top of eval_native_static_syntax_method_result that resolves $this via eval_static_syntax_instance_receiver and calls eval_native_constructor_with_evaluated_args bound to it, before the generic (non-constructor) metadata lookup runs. This uses only the existing AOT constructor registry/bridge -- no PHP source text is synthesized or parsed at runtime.
Evidence: gate.php cls5 went from DIFFERS (elephc fatal on parent::__construct) to IDENTICAL; sf404.php (real Symfony boot) progressed from failing at FormatException declaration to FormatException actually constructing and throwing with the correct sprintf()-formatted message
Verified by: tests/codegen/eval_native_method_retention.rs::test_eval_class_extending_a_native_exception_can_call_native_parent_construct; revert sentinel reproduced the original 'unsupported StaticMethodCall expression' text; php -n 8.5.6 oracle (cls5 probe, the FormatException-shaped constructor-promotion + sprintf() case)
