# Splitting the emitted .s for parallel `as`: cut the emission order into contiguous runs, never bin-pack (an emitted data record depends on __data adjacency)

> Measured prototype read only, Python, 2026 09 03 on the 33.3 MiB .s of examples/symfony app/freshprobe2.php 50,217 at…

Measured prototype (read-only, Python, 2026-09-03) on the 33.3 MiB `.s` of `examples/symfony-app/freshprobe2.php` (50,217 atoms): assembling N contiguous slices of the EMISSION ORDER in parallel gives N=2 1.51x, N=4 2.84x, N=8 4.08x, N=16 5.15x over the single blocking `as` (`src/linker/mod.rs`), with the program's stdout+exit equal, the symbol set equal and `__text` size delta 0 at every N; N=1 re-emitted is a `cmp`-identical object. Scaled to the release Symfony baseline (assemble 97.9 s of 164 s) that is ~90 s total. GREEDY BIN-PACKING by byte size links fine, has byte-identical `__text` and an identical 89,414-symbol table, and the binary DIES AT STARTUP on `require('6e3fae29...')`: a length-prefixed `.ascii` record reads its NEIGHBOUR's field, i.e. some emitted data record relies on adjacency inside `__data` that neither the linker nor the symbol table can see. Hence the rule: contiguous slices only (4.08x instead of 5.01x at N=8). Four real hazards any Rust implementation must handle: (1) `as` REFUSES a conditional branch to an external symbol (`conditional branch requires assembler-local label`, 26,149 errors = one per cross-unit `b.cond`), so "rely on relaxation" is not a policy: either keep caller and callee in one unit (0 cross-unit branches at every N with the binding policy) or rewrite `b.cond target` into `b.!cond skip; b target` (+4 bytes each, `__text` +104,576 on this probe); (2) 40,850 of 50,191 top-level symbols are plain Mach-O locals (no `.globl`/`.private_extern`) and must get `.private_extern` in the defining unit when referenced from another unit (8,166 at N=8); (3) 557 data atoms carry `.quad` with no alignment directive of their own (8-aligned only by what precedes them) and need `.p2align 3` (`ld: pointer not aligned in '_str_4'` otherwise), zero cost when already aligned; (4) `.data`/`.comm` switches and the `.private_extern` footer are file-global state replayed per unit. Identity gate for the implementation: N=1 must reproduce today's `.s` byte for byte (old-vs-old), N>1 must equal N=1 on program output and symbol set (new-vs-new); `aarch64_relax` decides by source byte distance so never compare old `.s` against split output. `--emit-asm` and `--web` are exclusive (`src/cli.rs`), so the time oracle (`index.php --web`) and the identity oracle (non-web) are different runs. Detailed scripts and results: session scratchpad `perf/b1-proto/` (split_as.py, matrix.py, link.py, results.md, b1-design.md).
Evidence: Matrix of 3-run minima at N=1,2,4,8,16 with load average 6.1–8.0; program stdout+exit diff empty, `nm` symbol sets equal, `__text` delta 0 for the contiguous policy; greedy-packed binary exits 1 with empty stdout at startup; A-only policy: 26,149 assembler errors; independent control: a 20 MB corpus `.s` split in 2 stays identical to the unsplit build and to php -n.
Verified by: Python prototype run against the real elephc-emitted .s and the real link line; php -n oracle for the control corpus
