# Ref-literal round-2: decref_any for de-packed hashes, binop operand release, prelude-aware ref-ensure hoist, hash-typed conditional merges

> Ref literal desugar correction round 1 branch reconcile/dirname symfony fixed four defect families with general mecha…

Ref-literal desugar correction round 1 (branch reconcile/dirname-symfony) fixed four defect families with general mechanisms: (1) A statically Array-typed EIR release must dispatch on the RUNTIME heap kind (`__rt_decref_any`), not `__rt_decref_array`: a slot whose fresh `[]` was de-packed to hash storage by `$t[$k] = &$v` (or any string-keyed write) keeps the stale packed flow type, and the packed free path leaks the hash's buckets and reference-cell shares (~1-2 blocks/loop-iteration). Fixed in lower_release (src/codegen_ir/lower_inst/ownership.rs). (2) `hash_get` with a Mixed result and `MixedNumericBinop` results are OWNING temporaries (fresh `__rt_mixed_from_value` boxes) already classified by value_is_owning_temporary, but consumers must release them; lower_mixed_numeric_binary now releases owned operands after the op (this also fixed the pre-existing 1-block/iter intermediate-binop leak in chained `$acc + $a['x'] + $a['y']`). (3) The entry-block LocalRefEnsure hoist walk (collect_ref_ensure_locals in src/ir_lower/function.rs) must descend into EXPRESSION positions to find RefAssignToTarget statements hidden in ExprKind::Assignment preludes (the array-literal by-ref desugar); otherwise a ref-bind in an untaken ternary/`??` branch leaves later LoadRefCell reads pointing at a raw slot value → SIGSEGV. (4) Ternary/`??`/match merge temps for a ref-literal-desugar branch must stay typed AssocArray{Mixed,Mixed} (materialized_expr_type_for_merge + a gated skip of the syntactic-fallback widening in branch_merge_result_type); a Mixed merge temp boxes the hash and key reads bypass the tag-11-aware hash-get path, printing nothing. Duplicate literal keys use PHP replace semantics via an `unset($tmp[key])` guard emitted before plain keyed entries that follow a ref entry (non-literal keys bound once to a hidden temp).
Evidence: Repros /tmp/refprobe p15a/p15d/p15e/p15/p21 now PHP-identical; h01/h03 loop probes went from 3-5 leaked blocks/iter to --heap-debug clean (control h02 also clean); references suite 117/0, runtime_gc 126/0, error_tests baseline-2 only.
Verified by: cargo test --test codegen_tests references (117/0), runtime_gc (126/0), parser_tests (424/0), ir_backend_smoke_test (255/0), --heap-debug probe runs
