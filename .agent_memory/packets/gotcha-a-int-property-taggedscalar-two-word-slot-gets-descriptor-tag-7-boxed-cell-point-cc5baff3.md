# A ?int property (TaggedScalar, two-word slot) gets descriptor tag 7 "boxed cell pointer", so object-to-hash readers dereference the null sentinel: var_dump/json_encode/serialize/(array)/== segfault

> OPEN as of 2026 09 03 diagnosed, reduced, not yet fixed; an agent is on it . A ?int / int|null property has codegen r…

OPEN as of 2026-09-03 (diagnosed, reduced, not yet fixed; an agent is on it). A `?int` / `int|null` property has `codegen_repr() == TaggedScalar`, i.e. a TWO-word slot (payload at `offset`, runtime tag word at `offset+8`). `prop_value_tag` in `src/codegen_support/runtime/data/user.rs` (around :3091) falls through `_ => 7` for it, so the emitted property descriptor row (`_class_serprop_N = {count, name, len, offset, tag 7}`) claims the slot holds a boxed Mixed CELL POINTER. `__rt_object_to_hash` (`src/codegen_support/runtime/objects/object_vars.rs` ~:165, both arches) then boxes `{tag 7, lo = raw payload}` through `__rt_mixed_from_value`; for a null the payload is `NULL_SENTINEL` (0x7ffffffffffffffe, `src/codegen_support/sentinels.rs`), and `__rt_mixed_unbox` peels tag 7, follows `lo`, and faults (lldb: `_rt_mixed_unbox + 8` ← `_rt_mixed_cast_bool + 16` ← the PHP method; x9 = 7, x10 = sentinel). Four-line reproducer: `class A { public ?int $n = null; } foreach ((array) new A() as $k => $v) var_dump($v);` (php prints `n=NULL`, elephc segfaults; `= 5` crashes too). Blast radius measured: `var_dump`, `print_r`, `var_export`, `json_encode`, `serialize`, `get_object_vars`, `(array)`, `==` all SIGSEGV on ANY object with one `?int` property; `?float`/`?string`/`?bool`/`?array` are fine (other reprs), `$obj->n` and `clone` fine. This is exactly why every Symfony `GET /` killed its worker: `Symfony\Component\DependencyInjection\Definition::__serialize()` does `foreach ((array) $this as $k => $v)`. Suggested fix: a DISTINCT descriptor tag for TaggedScalar-repr properties, translated at boxing sites to `{tag = the slot's own tag word, lo = payload, hi = 0}` via a shared `__rt_mixed_from_prop_slot` wrapper, plus one arm per direct-render reader (~14 sites × 2 arches) and the reverse direction (`unserialize` writing the two-word slot back).
Evidence: lldb backtrace and registers on the --keep-symbols Symfony worker; emitted asm `_class_serprop_0 = {…, offset 8, tag 7}`; the 4-line reproducer exits 139 under elephc and prints n=NULL under php -n; reader-by-reader blast-radius probes.
Verified by: lldb on the worker; standalone reproducers vs php -n (agent report 2026-09-03)
