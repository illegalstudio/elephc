# PHP stream oracle artifacts

This directory contains generated evidence for the frozen PHP 8.5.6 stream
compliance campaign. The normative source is php-src commit
`fcc29c8d6d6ee6f5ba2d941f0a2a6ea6aa6ee633`; Elephc source code is never used
to invent expected PHP values. Runtime evidence is authoritative only when its
profile says `binary_source_attestation: source-build`.

## Profiles

Each build-dependent manifest lives at the specification-mandated path:

```text
manifests/streams/php-8.5.6/<target>/<build-profile>.json
```

The `macos-aarch64/homebrew-no-ini.json` profile is exploratory evidence
generated by the Homebrew PHP 8.5.6 CLI with `-n`, locale `C`, and timezone
`UTC`. That installed binary is not attested as having been built from the
frozen commit, so the manifest says `external-unverified` and keeps
`profile-binary-source-attestation` open. It cannot close any normative gate.

An authoritative profile must use a PHP CLI built from the frozen checkout,
select `--binary-attestation source-build`, and provide the exact build
directory and compiler JSONL capture. The resulting manifest records the Git
tree, tracked-clean state, build inputs, binary hash, and normalized compiler
capture. It also freezes the compiler binary/version, operating-system release,
`uname`, make/linker versions, and the PHP binary's dynamic-library resolution.

Linux artifacts must be captured from target-exact PHP 8.5.6 builds for their
exact architectures. Container emulation is suitable for Gate 0 declaration,
constant, and harness capture when the manifest records the observed target;
it is not a substitute for later native timing, socket, TLS, or supported-target
acceptance runs. A macOS artifact must never be copied and relabelled as Linux.

## Reproduction

Build each `streams-full` CLI inside the exact target environment. Start from
the frozen checkout, run `buildconf --force`, and configure an out-of-tree build
with this common profile:

```bash
(cd /path/to/php-src && ./buildconf --force)
mkdir -p /path/to/php-build
cd /path/to/php-build

CC=/usr/bin/clang /path/to/php-src/configure \
  --prefix=/path/to/php-build/install \
  --disable-all \
  --enable-cli \
  --disable-cgi \
  --disable-phpdbg \
  --enable-ftp \
  --enable-phar \
  --enable-sockets \
  --with-openssl \
  --with-zlib \
  --with-bz2 \
  --with-iconv \
  --with-zip \
  --without-sqlite3 \
  --without-pdo-sqlite

: > /path/to/php-build/compile-commands.jsonl
ELEPHC_ORACLE_CC_LOG=/path/to/php-build/compile-commands.jsonl \
ELEPHC_ORACLE_REAL_CC=/usr/bin/clang \
make -C /path/to/php-build -j4 \
  CC=/path/to/elephc/tools/php_oracle/capture_cc.py
```

Package-manager include/library overrides are target-specific and must be
passed explicitly when needed. The resulting manifest freezes the literal
configure command, so a reproduction cannot silently substitute different
inputs. Use the same compiler for `configure` and the captured `make`; mixing
GCC feature detection with a Clang build can select incompatible php-src JIT
register paths.

Generate reachability first, then a preliminary PHP surface, the Elephc drift
ledger, and finally the manifest that binds all companion evidence:

```bash
python3 tools/php_oracle/extract_reachability.py \
  --compile-log /path/to/php-build/compile-commands.jsonl \
  --php-src /path/to/php-src \
  --build-dir /path/to/php-build \
  --target macos-aarch64 \
  --build-profile streams-full \
  --clang /usr/bin/clang \
  --directives-preprocessor /usr/bin/clang \
  --jobs 4 \
  --write

python3 tools/php_oracle/index_corpus.py --write

python3 tools/php_oracle/streams_manifest.py \
  --php-bin /path/to/php-build/sapi/cli/php \
  --php-src /path/to/php-src \
  --target macos-aarch64 \
  --build-profile streams-full \
  --reachability \
    tests/php_oracle/reachability/streams/php-8.5.6/macos-aarch64/streams-full.json \
  --binary-attestation source-build \
  --build-dir /path/to/php-build \
  --compile-log /path/to/php-build/compile-commands.jsonl \
  --corpus-index tests/php_oracle/corpora/streams/gate0.json \
  --write

cargo run --quiet --example gen_builtins -- \
  --streams-compliance \
  --target=macos-aarch64 \
  > /tmp/elephc-stream-surface-macos-aarch64.json

python3 tools/php_oracle/export_elephc_drift.py \
  --php-manifest \
    tests/php_oracle/manifests/streams/php-8.5.6/macos-aarch64/streams-full.json \
  --target macos-aarch64 \
  --build-profile streams-full \
  --elephc-json /tmp/elephc-stream-surface-macos-aarch64.json \
  --write

python3 tools/php_oracle/streams_manifest.py \
  --php-bin /path/to/php-build/sapi/cli/php \
  --php-src /path/to/php-src \
  --target macos-aarch64 \
  --build-profile streams-full \
  --reachability \
    tests/php_oracle/reachability/streams/php-8.5.6/macos-aarch64/streams-full.json \
  --binary-attestation source-build \
  --build-dir /path/to/php-build \
  --compile-log /path/to/php-build/compile-commands.jsonl \
  --drift-ledger \
    tests/php_oracle/drift/streams/php-8.5.6/macos-aarch64/streams-full.json \
  --corpus-index tests/php_oracle/corpora/streams/gate0.json \
  --write
```

Repeat that pipeline inside `linux-aarch64` and `linux-x86_64`, using their
exact source-built CLIs and target names. Once all three profiles exist,
regenerate the final three manifests so each one can attest that its sibling
profiles are present. Clang remains the authoritative LLVM replay compiler; on
toolchains where it lacks `-fdirectives-only`, pass GCC explicitly through
`--directives-preprocessor` and retain its path/version in the artifact.

```bash
python3 tools/php_oracle/streams_manifest.py \
  --php-bin /opt/homebrew/Cellar/php/8.5.6/bin/php \
  --php-src /tmp/elephc-php-src-dbjWuE/php-src \
  --target macos-aarch64 \
  --build-profile homebrew-no-ini \
  --check

python3 tools/php_oracle/streams_manifest.py \
  --php-bin /tmp/php-build/sapi/cli/php \
  --php-src /tmp/php-src \
  --target macos-aarch64 \
  --build-profile streams-full \
  --reachability \
    tests/php_oracle/reachability/streams/php-8.5.6/macos-aarch64/streams-full.json \
  --binary-attestation source-build \
  --build-dir /tmp/php-build \
  --compile-log /tmp/php-build/compile-commands.jsonl \
  --drift-ledger \
    tests/php_oracle/drift/streams/php-8.5.6/macos-aarch64/streams-full.json \
  --corpus-index tests/php_oracle/corpora/streams/gate0.json \
  --check

python3 tools/php_oracle/streams_manifest.py --validate-all

python3 -m unittest discover \
  -s tests/php_oracle/tests \
  -p 'test_*.py'
```

Use `--write` instead of `--check` only when intentionally refreshing the
artifact from the same frozen source/build. The generator rejects a different
php-src commit, PHP release, or target and writes canonical JSON atomically.

Each oracle case is executed twice. The raw run executes `main.php` unchanged
and is authoritative for exact stdout/stderr bytes, process status, signal,
timeout, and filesystem changes. The instrumented run starts from a fresh
sandbox and adds ordered diagnostics, exception data, return values, and
case-declared observations. Binary values use base64, byte length, and SHA-256;
floats use their exact big-endian IEEE-754 bits.

```bash
python3 tools/php_oracle/run_case.py \
  --php-bin /tmp/php-build/sapi/cli/php \
  --profile-manifest \
    tests/php_oracle/manifests/streams/php-8.5.6/macos-aarch64/streams-full.json \
  --case-dir tests/php_oracle/cases/streams/gate0/binary-diagnostics \
  --check
```

The ordered wrapper, transport, and filter arrays preserve PHP's observable
registry order. Declaration maps are sorted. Normalization is not performed by
this manifest generator.

The manifest also extracts the complete user-wrapper callback protocol directly
from `main/streams/userspace.c`. Each callback records its source definition,
invocation arity, argument-producing C statements, and by-reference positions;
the callback inventory is never maintained as a second hand-written table.
