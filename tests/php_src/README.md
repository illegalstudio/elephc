# php-src fixtures

Vendored PHPT files from the `php/php-src` `PHP-8.6` branch, kept as provenance for the
Rust fixtures generated from them. Tests never parse these files at runtime.

| Directory | Source | Rust fixture |
|---|---|---|
| `ext/date/tests/time/duration` | `ext/date/tests/time/duration` | `tests/codegen/time_duration_php_src.rs` (generated by `scripts/gen_php_src_time_duration_cases.py`) |
| `ext/standard/tests/math/clamp.phpt` | `ext/standard/tests/math/clamp.phpt` | `tests/codegen/math/clamp_php86.rs` |
| `ext/intl/tests/grapheme_strrev*.phpt` | `ext/intl/tests/grapheme_strrev*.phpt` | `tests/codegen/strings/grapheme_strrev_php86.rs` |
| `Zend/tests/readonly_props/readonly_with_default*.phpt` | `Zend/tests/readonly_props` | `tests/codegen/oop/readonly_property_defaults_php86.rs` |
| `Zend/tests/readonly_props/serialization.phpt` | `Zend/tests/readonly_props` | the defaulted-property portion of the same Rust module |
| `ext/date/tests/time/duration/serialize.phpt` | `ext/date/tests/time/duration` | `tests/codegen/time_duration_serialization.rs` |
| `ext/uri/tests/**/{builder,getters}/*.phpt` (PHP 8.6) | `ext/uri/tests` | `tests/codegen/uri86_php_src.rs` (198 of 204 fixtures pass; 6 are skipped for opaque-path spaces, a mixed-object array_map comparison, and the typed-property by-reference shape) |
| `ext/standard/tests/strings/pack*.phpt`, `unpack*.phpt` | `ext/standard/tests/strings` | `tests/codegen/strings/pack_unpack_php86.rs` (10 focused tests; 32-bit-only and the `X` bug fixture are vendored for provenance but not asserted) |
| `ext/standard/tests/poll/*.phpt` | `ext/standard/tests/poll` | `tests/codegen/io/io_poll_php86.rs` (the shared `poll.inc` helper is inlined because elephc's checker rejects its untyped helper shapes; the upstream set contains no separate edge or hang-up fixtures) |
| `ext/standard/tests/streams/stream_errors_*.phpt` | `ext/standard/tests/streams` | `tests/codegen/io/stream_errors_php86.rs` and `tests/codegen/io/stream_errors_corpus_php86.rs` (all 14 runnable fixtures pass; 4 are `--SKIPIF--`-only) |
| `Zend/tests/partial_application/*.phpt` | `Zend/tests/partial_application` | `tests/codegen/oop/partial_application_php86.rs` (the selected fixtures exercise evaluation order, forwarding, variadics, scope, constants, and error-free creation) |
| `ext/reflection/tests/ReflectionParameter_getDocComment_{basic,indented}.phpt` | `ext/reflection/tests` | `tests/codegen/oop/reflection_parameter_doc_comments_php86.rs` (the basic fixture omits closure/arrow reflection because dynamic `ReflectionFunction` construction is unsupported) |
| `ext/reflection/tests/ReflectionProperty_is{Readable,Writable}_*.phpt` | `ext/reflection/tests` | `tests/codegen/oop/reflection_property_access_php86.rs` (the readonly fixture replaces dynamic `ReflectionClass` construction with a literal class name and omits the readonly write inside `__clone`) |

Fixtures that depend on engine internals elephc does not expose (the internal
`__unserialize` property loader, `ReflectionProperty::setRawValue`, clone-with, and
dynamic-name readonly writes) stay in the corpus as reference material and are listed
in the relevant test module's preamble with the reason they are not executed.
