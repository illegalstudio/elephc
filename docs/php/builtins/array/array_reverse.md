## array_reverse()

```php
function array_reverse(array $array, bool $preserve_keys = false): array
```

Returns an array with the elements in reverse order.

**Parameters**:
- `$array` (`array`)
- `$preserve_keys` (`bool`), default `false`, optional

**Returns**: `array`
