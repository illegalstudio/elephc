PHP 8.6 is a minor release. elephc keeps the existing `--php-version` profiles and
adds the 8.6 behaviour behind `--php-version=8.6` where the change is profile
sensitive.

## Delivered

| Feature | Notes |
|---|---|
| `Time\Duration` | `final readonly` value class with `seconds`, `nanoseconds`, `negative`; every `from*()` factory; `negate()`, `absolute()`, `add()`, `sub()`, `multiplyBy()`, `divideBy()`, `compare()`; comparison operators through the internal object handler; overflow raises `Time\TimeException`; serialization and `__unserialize()` validation. The php-src `ext/date/tests/time/duration` corpus is migrated into `tests/codegen/time_duration_php_src.rs` and the serialization fixture into `tests/codegen/time_duration_serialization.rs`. |
| `Time\TimeException` | Extends `\Exception`; every overflow and ISO-8601 parse failure uses php-src's message text. |
| `clamp()` | Full `mixed` signature. Int, float, and string operands keep the typed runtime path; boolean, null, array, and object operands go through php-src's own polyfill, so PHP's cross-type comparison rules apply. `DateTime`/`DateTimeImmutable` gained the internal comparison adapter this needs. The upstream `ext/standard/tests/math/clamp.phpt` fixture is transcribed in `tests/codegen/math/clamp_php86.rs`. |
| `grapheme_strrev()` | Now classified as `ext/intl` (PHP 8.6) instead of an elephc extension. Both upstream `ext/intl/tests/grapheme_strrev*.phpt` fixtures pass, including the UBRK_DONE regression and the Arabic grapheme-cluster case. |
| Default trim mask | `trim()`, `ltrim()`, `rtrim()` and `chop()` include form feed (`\x0C`) under `--php-version=8.6`, and leave it untouched on 8.5 and earlier. |
| Readonly property defaults | A readonly instance property may declare a default value, including inside a `readonly class`. The default initializes the slot before the constructor runs, so later writes (including from the constructor) raise `Cannot modify readonly property`. Inheritance, get-only interface properties, and serialization follow php-src's `Zend/tests/readonly_props/readonly_with_default*.phpt`. |
| WeakMap reference assignment | `$map[$obj] = &$value` accepts the reference-assignment syntax: the entry is created when absent (PHP 8.6's change), shares one storage with the source local, and is released when the weak key dies or the map is destroyed. Implemented as a parser desugaring into an ordinary value store plus the existing array-element `$value = &$map[$obj]` alias, so a plain-array `$arr[$key] = &$value` works too. A non-variable source still needs a container reference-store primitive. Covered by `tests/codegen/core_classes/weak_map_places.rs`. The pre-existing array-element reference alias leaks its tag-11 cell on `unset` (the manual two-statement form reproduces it), tracked separately. |
| Stream error API | `StreamErrorMode`, `StreamErrorStore`, `StreamErrorCode`, final readonly `StreamError`, `StreamException::getErrors()`, `stream_last_errors()`, `stream_clear_errors()`, and the `stream.error_mode` / `error_store` / `error_handler` context options. `fopen()` runs through an error-aware wrapper: Error mode warns, Exception mode throws, Silent suppresses, and the store/handler policies apply. User-wrapper `stream_read()` excess data is truncated to the requested chunk. Under 8.6 the runtime records the event in program globals, and injected `fread()` / `stream_get_contents()` wrappers build `UserspaceInvalidReturn` errors, apply the stream context's mode/store/handler policy, accumulate every read in one operation, and preserve an outer operation's pending errors across nested reads. A `stream_select()` wrapper reports the two terminating `stream_cast()` errors (`NotImplemented` and `CastNotSupported`) with the same policy. `fwrite()` reports missing or over-reported `stream_write()` calls, `file_get_contents()` dispatches missing reads for user wrapper schemes, and `stream_context_set_option()` / `stream_context_set_options()` keep the per-context option map current. `stream_copy_to_stream()` accepts its 8.6 `$context` argument and applies copy-time read and write userspace errors together in a single handler invocation, while `stream_socket_pair()` and `stream_is_local()` accept their 8.6 context argument. Earlier profiles keep emitting the legacy warning directly. The runtime now recognizes `php://memory` / `php://temp` for paths known only at run time, and literal, computed, nested-container, and materialized `$GLOBALS` reads/writes resolve to program-global storage from any scope, and a computed write can create a global whose name exists only at run time; a bare `$GLOBALS` snapshot supports `count()` and `foreach`. The 18-fixture upstream corpus is vendored; `tests/codegen/io/stream_errors_corpus_php86.rs` locks in all 14 runnable fixtures and records the 4 `--SKIPIF--`-only fixtures; the runner ignores blank-line interleaving and names the concrete exception class where the checker cannot dispatch through `Throwable`. |
| Deprecations | `is_a()` / `is_subclass_of()` with a string subject and `$allow_string = false` emit php-src's deprecation, `SplFileObject::fgetcsv()` / `fputcsv()` / `setCsvControl()` / `getCsvControl()` are reported as deprecated, and a statically object-typed `$vars` argument to `mb_convert_variables()` raises `Passing an object for argument #N ($vars) … call get_object_vars() first instead`. `mysqli::stmt_init()` / `mysqli_stmt_init()` ("use mysqli::prepare() instead") and `mysqli::get_charset()` / `mysqli_get_charset()` ("did you mean mysqli_character_set_name()?") carry php-src's `#[\Deprecated(since: '8.6', …)]` marker in both their method and procedural forms. All are profile-gated to 8.6 and covered by `tests/error_tests/warnings.rs` and `tests/error_tests/mysqli.rs`. `ArrayIterator`'s deprecated methods and `metaphone()`/`doubleval()` are absent from elephc. |
| Fileinfo 8.6 | The managed libmagic package moves to file 5.48 (catalog version, source URL, size and SHA-256 updated). `finfo_file()` already reads `data://`, `file://`, `php://filter`, `compress.zlib://`, `compress.bzip2://`, `php://stdin` and the HTTP/HTTPS/FTP/FTPS wrappers through the stream layer; the existing remote-wrapper and stream-diagnostics fixtures cover those paths. |
| GMP 8.6 | `gmp_powm_sec()` (side-channel quiet modular exponentiation) and `gmp_prevprime()` (largest prime below the operand, with its `$definitely_prime` by-reference flag). The release's diagnostics are applied too: `gmp_fact`/`gmp_pow`/`gmp_binomial`/`gmp_root`/`gmp_rootrem` name the unsigned-long bound, GMP integer strings containing NUL bytes raise `ValueError`, the `**`/`<<`/`>>` operators report the unsigned-long range, and `gmp_powm()`''s zero-modulus `DivisionByZeroError` names `$modulus`. Covered by `tests/codegen/gmp_php86.rs`. |
| `stream_socket_get_crypto_status()` | Reports the pending TLS handshake/read operation without blocking, with the `STREAM_CRYPTO_STATUS_NONE` / `WANT_READ` / `WANT_WRITE` constants. elephc completes every handshake synchronously, so a stream with an attached session reports `NONE`; a stream without an SSL layer warns "This stream does not support SSL/crypto" and also reports `NONE`, matching php-src. Covered by `tests/codegen/io/stream_crypto_status_php86.rs`. |
| `error_include_args` | PHP 8.6's Core INI directive is registered with its `0` default and `INI_ALL` access, so `ini_get()` / `ini_set()` / `--ini` overrides and `ini_get_all()` details work. elephc's static diagnostics do not render argument values yet, so the directive has no effect on compile-time error text; this is the known deviation for this row. |
| Core 8.6 polish | `ReflectionClassConstant::__toString()` renders boolean and scalar constants in php-src's `Constant [ … ] { … }` form; `ini_get_all()` detail rows now include `builtin_default_value`; and `ini_set('mbstring.detect_order', …)` moves the live detection order immediately. The DateTime factory return types are already the concrete class, which matches the new tentative `static` metadata. `filter_var_array`, readline, `header_register_callback`, `register_tick_function`, `mysqli.default_port`, `Openssl\OpensslException` and the AIX `PHP_OS_FAMILY` value remain out: their extensions are not implemented or the target is unsupported. |
| `ReflectionAttribute` namespace helpers | `getShortName()`, `getNamespaceName()`, and `inNamespace()` describe the attribute class name for global, namespaced, and aliased attribute spellings. The attribute factory stores the split at creation, mirroring the class-level reflector, and `tests/codegen/oop/attributes.rs` covers all three spellings. `ReflectionConstant::inNamespace()` remains unavailable because elephc does not implement the PHP 8.4 global-constant `ReflectionConstant` class. |
| Phar 8.6 | `Phar::addEmptyDir()` rejects the magic `.phar` directory forms php-src reserves (`".phar"`, `"/.phar"`, `".phar/<path>"`) with php-src's `BadMethodCallException`, while `.phar`-prefixed ordinary names (`.pharma`) stay writable; directory entries are recorded as `<name>/`. `PharException` is declared. `Phar::mungServer()` validates its array exactly like php-src (`No values`, `Too many values`, `Non-string value`, `Invalid value`, naming the four accepted `$_SERVER` keys) and accepts reference elements; shipping it also fixed the builtin-SPL discovery loop that re-lowered a static metadata method forever (the `is_static` guard saw only instance methods). Covered by `tests/codegen/io/phar_php86.rs`. The 8.6 `.phar` include auto-interpretation rule and `buildFromDirectory()` / `buildFromIterator()` `SplFileInfo` overrides remain out. |
| Filtered-stream parameters | `stream_filter_append()` / `stream_filter_prepend()` now read the associative `$params` form: `level` for `zlib.deflate`, `blocks` / `work` for `bzip2.compress`, and PHP 8.6's `write_seek_mode` (`preserve`, `reset`, `strict`) for the zlib, bzip2, iconv, `convert.*`, and `string.*` filters. An invalid mode emits php-src's `"write_seek_mode" filter parameter must be one of "preserve", "reset", or "strict"` followed by `Unable to create or locate filter "<name>"`, and `stream_filter_append()` returns `false`; earlier profiles ignore the key like php-src. Filtered streams stay ordinary descriptors, so `stream_select()` works on them. Covered by `tests/codegen/io/stream_filter_write_seek_mode_php86.rs`. `fseek()` enforces the three modes for `zlib.deflate` and `bzip2.compress`: `strict` rejects every write-chain seek with php-src's `Stream filter <label> is never seekable` warning, `reset` rejects non-start seeks with `is seekable only to start position` (a start seek succeeds), and `preserve` accepts any offset. The mode and filter label are recorded per descriptor. An allowed seek also resets the underlying stream state like php-src (zlib `deflateReset`, bzip2 end + reinitialize), so after `ftruncate(0)` + `fseek(0)` the new writes decode to the new payload. Covered by `tests/codegen/io/stream_filter_write_seek_mode_php86.rs`. The same seekability rule covers the `string.*`, `convert.*` and `convert.iconv.*` write filters with php-src's labels (`convert.*` for the convert factories), and `rewind()` consults the mode (strict rejects it, reset/preserve allow it). The read-side defaults are enforced too: `zlib.inflate`, `bzip2.decompress`, the `convert.*` and `convert.iconv.*` read filters are start-only (`PSFS_SEEKABLE_START`), rejecting non-start seeks with `Stream filter <label> is seekable only to start position` while a start seek succeeds. `rewind()` runs the same reset hooks, so an allowed rewind also starts a fresh compression stream. |
| Stream flush/close failures | Under `--php-version=8.6`, `fclose()` returns `false` when a stream's flush fails, so a user wrapper whose `stream_flush()` returns `false` reports a failed close; `file_put_contents()` and `copy()` report a failed flush/close as failure instead of a byte count. Earlier profiles keep the previous results. `copy()` also rejects an unreadable source and copies an empty file successfully on every profile. Covered by `tests/codegen/io/stream_close_failure_php86.rs`. |
| Objects stored in constants | A class constant, a top-level `const`, or a `define()` value initialized with `new` is materialized once, so every read shares that object: `Config::DEFAULTS->timeout = 30` is visible to later reads, `Config::DEFAULTS === Config::DEFAULTS` holds, and arrays held by the object mutate normally. PHP 8.5 cannot compile the `new` initializer, so the profile reports nothing to compare against; see the deviation below. |

## Deliberately deferred

These PHP 8.6 items are not implemented yet. Each has a tracked follow-up; the
list is here so a PHP 8.6 program that depends on one fails visibly during review
instead of during production.

| Item | Why it is deferred |
|---|---|
| Direction-aware property resolution, const object property writes, function-argument error display, closure optimizations, TLS session resumption, SNMP updates | Smaller upstream changes with no standalone user-visible surface in elephc yet. |

## Known deviations

- `new` in a `const` or class-constant initializer, and a property write through such a
  constant (`Config::DEFAULTS->timeout = 30`), are accepted on every `--php-version`
  profile. php 8.5 rejects both (`New expressions are not supported in this context`,
  `Cannot use temporary expression in write context`), so elephc is more permissive on the
  older profile rather than silently dropping the write.
- The PHP 8.6 URI builder corpus passes all 204 fixtures.
- `pack()`/`unpack()` are declared by an AOT prelude. Literal `eval` source that names them
  gets the prelude through usage detection; opaque dynamic eval source needs `--with-pack`. The prelude's float conversions link the small
  `elephc_pack` bridge, so a program that never calls `pack`/`unpack` links nothing.
- `Io\Poll` exposes `Epoll` on Linux and `Kqueue` on Darwin as backend modes; the
  wait itself uses the shared `stream_select()` + zero-timeout `poll(2)` machinery
  rather than issuing epoll/kqueue syscalls directly, so `Event::EdgeTriggered`
  remains refused until a native wait exists.
  `EventPorts` and `WSAPoll` remain unavailable because elephc does not target
  Solaris or Windows. `get_debug_type()` is implemented and the upstream
  closed-handle fixture runs unchanged.
  `Watcher::getHandle()` returns the concrete `StreamPollHandle` type rather than the
  `Io\Poll\Handle` interface so the checker accepts the upstream
  `getHandle()->getStream()` pattern; the returned object still implements the interface.
- The stream error surface wraps every operation the 8.6 RFC defines one for: the
  error-aware `fopen()`, the user-wrapper reads (`fread()`, `stream_get_contents()`),
  `fwrite()`'s `stream_write()` accounting, `file_get_contents()`, `stream_select()`'s
  `stream_cast()` failures, `stream_copy_to_stream()`, and the context-option setters.
  Warnings are written to stderr; silent and exception modes suppress the `fopen()`
  warning.
- Parameter doc comments are attached, but `ReflectionFunction` cannot yet be constructed from a
  closure or arrow function, so those two parameter lists are parsed and stored without a
  user-visible reflection path. Doc comments on properties and hook methods themselves are not
  retained; only parameter comments are.
- Partial application of a magic `__call` / `__callStatic` dispatch, or of a receiver whose
  class cannot be resolved at compile time, is rejected with a diagnostic rather than
  synthesized. `new C(?)` is also rejected, matching PHP. Bound values use a generated typed
  identity closure at creation time; in a `declare(strict_types=1)` file a mismatch may be
  coerced where php-src raises `TypeError`, and the hidden variadic parameter makes the
  generated closure appear variadic to reflection.
- `ReflectionProperty::isReadable()` and `isWritable()` expose `mixed $object` rather than
  `?object $object`, so the static checker accepts dynamic values such as `new $scope`.
  The initialization probe casts the object to an array and compares the mangled backing
  slot; a readonly initialized property is reported writable inside the matching
  `__clone` frame, which is php-src's reinitializable window.
- A structurally malformed serialized payload for `Time\Duration` (for example
  `O:13:"Time\Duration"::{}`) reaches the generic `unserialize()` warning and
  returns `false`; php-src wraps it in `Exception: Invalid serialization data`.
  Well-formed payloads with invalid fields go through `Duration::__unserialize()`
  and raise that exception.
- `new Time\Duration()` is rejected while compiling (the constructor is private),
  whereas php-src reports the same invalid program at run time. The factories are the
  only supported construction path in both implementations.
- A readonly property's default is enforced by the static checker for named
  writes. Dynamic-name writes (`$object->$name = …`) and `unset()` do not yet
  consult readonly state, matching the pre-existing dynamic-property gap rather
  than the 8.6 defaults change.
- The constructor/destructor deprecation helper runs once at startup and scans only
  unconditional top-level/namespace/include-once declarations. A class declared inside a
  runtime branch emits the diagnostic early instead of when that branch executes.
- An enum's `__debugInfo()` is rendered by `var_dump()` and `print_r()`; the magic-method
  visibility warning is not emitted yet.
- A trait composition that redeclares an `#[\Override]` constant with a different value is
  rejected as an incompatible duplicate trait constant before the override rule runs, so
  the diagnostic differs from php-src's override message while the program is still
  refused.
- `grapheme_strrev()` implements the common `Grapheme_Extend` ranges (Latin,
  Hebrew, Arabic, Indic, Thai, Tibetan, variation selectors, emoji modifiers) but
  not the complete UAX #29 rule set (`SpacingMark`, `Prepend`, regional
  indicators). The upstream fixtures pass.
